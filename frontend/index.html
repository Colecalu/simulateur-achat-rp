03 — LA RÈGLE DU JEU

Mêmes moyens.
Autres destinations.

Chaque mois, le même budget dans les deux cas. Côté achat, il paie le crédit et les charges ; côté location, le loyer. Ce qui reste est investi. À l’arrivée, on compare ce que vous possédez vraiment.

Est-ce qu’Æquo va me dire d’acheter ou de louer ?

Il compare les patrimoines calculés à la durée choisie, avec vos paramètres. Le résultat est conditionnel : modifier un loyer, un prix ou une hypothèse de marché peut changer la comparaison. Il ne remplace pas votre décision personnelle.

Pourquoi investir quand on reste locataire ?

Pour comparer avec le même effort financier. Le capital qui n’est pas utilisé comme apport et la différence disponible après le logement peuvent être investis. Cette discipline d’épargne fait partie de l’hypothèse de référence ; elle n’est pas automatique dans la vie réelle.

Qu’est-ce qui entre dans les calculs ?

Le financement, les frais d’acquisition, les charges de copropriété, la taxe foncière, les loyers, l’évolution du bien et celle des placements. Les portefeuilles capitalisent avant impôt ; leur fiscalité de sortie est prise en compte dans le patrimoine net affiché.

Le modèle ne couvre pas toutes les situations : notamment les frais de revente, les gros travaux imprévus ou les changements de vie.

Les scénarios prédisent-ils les marchés ?

Non. Un historique rejoue des évolutions passées sur votre projet ; une hypothèse teste un environnement possible. Ni l’un ni l’autre ne prédit l’avenir. Le projet est en développement et les données de scénarios sont encore provisoires : elles ne permettent pas de tirer une conclusion financière fiable à ce stade.

Dois-je connaître tous les montants pour commencer ?

Vous pouvez explorer un exemple, puis remplacer les valeurs par celles de votre projet. Commencez avec votre prix d’achat, un loyer comparable et votre situation financière. Affinez ensuite les frais et les hypothèses.

Où vont mes données ?

Les calculs s’effectuent dans votre navigateur. Cette version ne nécessite pas de compte. Le brouillon du simulateur est conservé localement sur votre appareil ; il n’est pas synchronisé entre vos appareils.
